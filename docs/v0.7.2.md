# v0.7.2 — Runner Portability and Reproducible Evidence

v0.7.2 is a maintenance and qualification release. It does not change the default `deepseek-v4-flash` model or repair/review prompts. It includes five Linux and CI fixes made after the v0.7.1 tag and improves the benchmark and runner evidence recorded by the repository.

## Linux and CI fixes closed into the release

- Enables Docker's containerd image store in CI so BuildKit SBOM/provenance attestations can be loaded and inspected.
- Maps POSIX bind-mounted worktrees to their non-root owner UID/GID and rejects root-owned workspaces instead of silently escalating.
- Performs an unthrottled final workspace-size scan so fast persistent writes cannot escape the sampled monitor.
- Uses a commit-pinned, account-free Trivy application-library Critical/High gate in public CI.
- Keeps the remaining create/delete burst gap explicit: the bind mount is monitored rather than backed by a true filesystem quota.

## Reproducible benchmark evidence

Benchmark report schema 5 adds a secret-free protocol record containing the Git revision and dirty state, manifest/config SHA-256 values, selected cases and modes, model identifiers, sandbox selection, and Python/platform information. Success, visible, holdout, and Success@1 rates include two-sided 95% Wilson intervals.

`pyfixagent-benchmark-compare` compares exact case/strategy/variant/repetition matches. It reports paired wins, losses, ties, an exact McNemar p-value, token and duration deltas, and failure-count changes. Manifest, case, repetition, strategy, or repository-mode drift returns exit status 2 by default; incomplete matched coverage returns status 3.

The 24 bundled cases remain a local curated benchmark. v0.7.2 makes no new real-world repair-rate claim.

## Portable finite runners

`containers/profiles.json` defines three Linux/amd64 CPython 3.12 profiles:

- `minimal`: pytest only, with five resolved packages.
- `scientific`: the existing 20-package pytest/NumPy/scikit-learn/matplotlib runner used by the bundled benchmark.
- `web`: pytest and Flask, with twelve resolved packages.

Every resolved package is bound to a wheel hash. The recorded qualification ran imports for all three images with networking disabled, a read-only root, non-root execution, dropped capabilities, and no-new-privileges.

CI includes scientific-runner policy tests under Docker and Linux Podman. The Docker job uploads a qualification bundle containing a CycloneDX SBOM, image inspection, BuildKit metadata, and startup/write-limit JSON and Markdown. Version tags build and smoke-test all three profiles before publishing the corresponding GHCR images with BuildKit SBOM/provenance and GitHub OIDC build provenance.

Release-critical third-party Actions are commit-pinned, and Dependabot now checks both Docker and GitHub Actions references weekly.

## Local runner qualification

The final local scientific image was built from the digest-pinned base and fully hashed lock on Docker Desktop 29.4.2. `pyfixagent-qualify-container --repeat 5 --probe-limits` produced 10/10 successful isolated invocations:

| Workload | First process | Repeated mean | Repeated p50 | Repeated p95 |
|---|---:|---:|---:|---:|
| Python startup | 1.165s | 1.475s | 1.537s | 1.958s |
| pytest startup | 4.022s | 4.878s | 4.672s | 5.787s |

These timings describe this host and include client/container overhead; they exclude image pulls and are not cross-machine performance claims. The persistent 32 KiB write against an 8 KiB growth budget was detected. The corresponding immediate create/delete burst was not detected, documenting the honest limit of sampling plus a final scan.

## Compatibility

- Trace schema remains 1.5.
- Benchmark manifest schema remains 3.
- Benchmark report schema advances from 4 to 5.
- Existing `run_benchmark` library callers remain valid; reports created directly use a `source: library` protocol marker unless metadata is supplied.
- Docker remains the configured default. Podman is selectable through the existing `sandbox.container.engine` field.
